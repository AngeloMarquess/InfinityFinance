# 💰 InfinityFinance — Controle Financeiro Pessoal

Aplicação web simples para controlar **receitas e despesas**, com **cálculo automático do saldo** e **persistência de dados** usando LocalStorage.

## 🚀 Funcionalidades
- ✅ Adicionar receitas e despesas
- ✅ Listar transações
- ✅ Calcular saldo automaticamente
- ✅ Salvar dados no LocalStorage

## 🛠 Tecnologias
- HTML5
- CSS3
- JavaScript (Vanilla)
